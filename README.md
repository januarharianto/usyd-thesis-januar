# Januar's PhD Thesis

This repository contains the source for my thesis submitted at the University of Sydney in 2019. It is written in R Markdown with Bookdown.

[View submitted thesis in the USYD repository](https://hdl.handle.net/2123/20420)

## Rendering the thesis

You need R with Bookdown and the packages used by the chapters, Pandoc, and a TeX distribution with XeLaTeX. The layout uses Minion Pro, Myriad Pro and PT Mono.

Open `thesis2019.Rproj` in RStudio and select **Build Book** in the Build pane, or open `index.Rmd` and click **Knit**. Both build the full thesis as `_book/thesis2019.pdf`.
